# 首次启动后连接 Wi-Fi 与蓝牙

- **场景**：已经进入 niri 或 Hyprland，需要连接无线网络和蓝牙设备
- **前提**：NetworkManager、BlueZ、`bluez-utils` 已安装
- **目标**：用命令行或图形界面完成连接，并让服务开机自启
- **工具**：`nmcli`、`nmtui`、`bluetoothctl`、`blueman`、`nm-connection-editor`

Wi-Fi 和蓝牙都由系统服务管理，桌面环境只负责显示状态栏。服务没有启动时，
点击状态栏不会有效果，所以先确认服务，再连接设备。

## 1. 先确认硬件和服务

```bash
nmcli device status
rfkill list
systemctl status NetworkManager bluetooth
```

需要看到：

- Wi-Fi 网卡的状态不是 `unavailable`
- 蓝牙适配器类似 `hci0`，并且 `Soft blocked: no`
- `NetworkManager` 和 `bluetooth` 都是 `active`

如果蓝牙服务没有启动：

```bash
sudo systemctl enable --now bluetooth
sudo systemctl enable --now NetworkManager
```

`NetworkManager` 负责 Wi-Fi、有线和 VPN；BlueZ 只负责蓝牙协议栈，
`bluetoothctl` 和 `blueman` 都是它的前端。

## 2. 连接 Wi-Fi

### 2.1 使用 nmtui

`nmtui` 是最省事的终端界面，安装 NetworkManager 后就有：

```bash
nmtui
```

选择：

```text
Activate a connection
```

然后选中目标 Wi-Fi，按回车并输入密码。连接成功后按两次 `Esc` 退出。

### 2.2 使用 nmcli

扫描附近网络：

```bash
nmcli device wifi rescan
nmcli device wifi list
```

连接普通 Wi-Fi：

```bash
nmcli --ask device wifi connect "Wi-Fi 名称"
```

`--ask` 会交互式询问密码，避免密码留在 shell 历史里。隐藏网络加参数：

```bash
nmcli --ask device wifi connect "Wi-Fi 名称" hidden yes
```

查看当前连接和地址：

```bash
nmcli connection show --active
nmcli device show wlp4s0
```

重新连接已有配置：

```bash
nmcli connection up "For-free-mesh"
```

断开或删除配置：

```bash
nmcli connection down "For-free-mesh"
nmcli connection delete "For-free-mesh"
```

### 2.3 使用图形界面

需要图形化编辑连接时，安装：

```bash
sudo pacman -S --needed network-manager-applet
```

然后打开：

```bash
nm-connection-editor
```

它可以配置 Wi-Fi、有线、VPN、代理和 802.1X 企业网络。日常切换网络仍然
推荐 `nmtui`，因为启动更快，也不依赖托盘。

## 3. 连接蓝牙

### 3.1 启动蓝牙服务

```bash
sudo systemctl enable --now bluetooth
systemctl status bluetooth
rfkill list
```

如果 `rfkill` 显示蓝牙被软禁用：

```bash
sudo rfkill unblock bluetooth
```

### 3.2 使用 bluetoothctl

进入交互界面：

```bash
bluetoothctl
```

依次执行：

```text
power on
agent on
default-agent
scan on
```

把耳机、键盘或鼠标切换到配对模式，等待设备出现：

```text
devices
```

看到目标 MAC 后执行：

```text
pair XX:XX:XX:XX:XX:XX
trust XX:XX:XX:XX:XX:XX
connect XX:XX:XX:XX:XX:XX
scan off
exit
```

`trust` 的作用是允许设备以后自动重连，建议对常用设备执行。键盘或鼠标
配对时如果提示输入 PIN，按设备说明书输入；有些设备只需要在终端确认
`yes`。

查看设备状态：

```bash
bluetoothctl info XX:XX:XX:XX:XX:XX
```

输出中出现 `Connected: yes` 即表示连接成功。要取消配对：

```text
disconnect XX:XX:XX:XX:XX:XX
remove XX:XX:XX:XX:XX:XX
```

### 3.3 使用 blueman

图形化管理更方便，安装：

```bash
sudo pacman -S --needed blueman
```

启动：

```bash
blueman-manager
```

在窗口中打开适配器、搜索设备、配对并连接即可。`blueman` 只是 BlueZ 的
图形前端，底层服务仍然是 `bluetooth.service`。

### 3.4 耳机和输入设备

- 蓝牙耳机：先 `pair`，再 `trust`，最后 `connect`；连接后可以用
  `pavucontrol` 或 `wpctl status` 确认音频输出设备。
- 蓝牙键盘：配对时可能需要输入设备上显示的 PIN；配对完成后执行
  `trust`，否则重启后可能不会自动连接。
- 蓝牙鼠标：部分鼠标在配对时会短暂断开，重新执行 `connect` 即可。
- 设备列表为空：把设备重新进入配对模式，并保持 `scan on` 至少十几秒。

### 3.5 重启后的自动连接

Wi-Fi 的已保存连接默认是 `autoconnect yes`，`NetworkManager` 开机自启后，
只要网络在范围内就会自动连接。可以用下面的命令确认或修改：

```bash
nmcli connection show "For-free-mesh"
nmcli connection modify "For-free-mesh" connection.autoconnect yes
```

蓝牙的 `trust` 只是允许设备自动重连，并不保证所有设备都会主动连回来。
键盘、鼠标和部分耳机可能自动连接，另一些设备需要登录后手动执行：

```bash
bluetoothctl connect XX:XX:XX:XX:XX:XX
```

如果希望图形化处理自动连接，可以启动 `blueman-applet`，或为常用设备写一个
systemd user service。`bluetooth.service` 没有启用时，蓝牙设备不会自动连接。

## 4. 状态栏入口

Waybar 的蓝牙模块已经配置为点击打开 `blueman-manager`，Wi-Fi 模块点击
打开 `nmtui`：

```text
network   -> kitty -e nmtui
bluetooth -> blueman-manager
```

修改 Waybar 的配置文件后需要重启 Waybar 才会生效；仅修改 `style.css`
时才会自动重载样式。

## 5. 常见问题

| 现象                           | 原因                         | 处理                                      |
|--------------------------------|------------------------------|-------------------------------------------|
| `bluetoothctl` 卡住没有输出    | `bluetooth.service` 没有启动 | `sudo systemctl enable --now bluetooth`   |
| 状态栏蓝牙显示 `no-controller` | 没有适配器或被 rfkill 禁用   | 检查 `rfkill list` 和 `lsusb`             |
| Wi-Fi 列表为空                 | 无线被关闭或驱动未加载       | `nmcli radio wifi on`，再检查 `dmesg`     |
| 连上 Wi-Fi 但不能解析域名      | DNS 或路由没有下发           | 检查 `nmcli device show` 和 `resolv.conf` |
| `nmcli` 提示需要密码           | 连接配置没有保存密码         | 重新执行 `nmcli --ask ... connect`        |
| 蓝牙配对成功但没有声音         | 音频 profile 没有切换        | 在 `pavucontrol` 的配置页选择 A2DP        |
| 重启后蓝牙设备不会自动连接     | 没有 `trust` 或服务未自启    | `bluetoothctl trust MAC`，检查服务状态    |
| Waybar 点击没有反应            | 对应程序没有安装             | 安装 `blueman` 或使用 `nmtui`             |

## 6. 验收清单

- `systemctl is-active NetworkManager` 输出 `active`
- `systemctl is-active bluetooth` 输出 `active`
- `nmcli device status` 中 Wi-Fi 状态为 `connected`
- `ping -c 3 archlinux.org` 能正常解析并收到回复
- `bluetoothctl info MAC` 显示 `Connected: yes`
- 点击 Waybar 的网络图标能打开 `nmtui`
- 点击 Waybar 的蓝牙图标能打开 `blueman-manager`
- 重启后 Wi-Fi 能自动连接；蓝牙按设备能力自动连接或手动重连
