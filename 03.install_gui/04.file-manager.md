# 文件管理器：GUI 与终端两套选择

文件管理器分两类：GUI 文件管理器负责桌面里的拖放、缩略图、挂载和右键菜单；
终端文件管理器（TUI）负责键盘操作、批量处理和快速预览。两者不是替代关系，
可以同时安装。

**一句话结论**：GUI 用 `thunar`，轻量、依赖少、能直接接入 `gvfs` 和
`udisks2`；终端继续用已装的 `ranger`，需要更强预览时再换 `yazi`。

本文以 Arch 官方仓库当前版本为准。体积是包自身的安装大小，不含依赖。

## 1. 先看候选

| 程序       | 技术栈            | 体积     | 适合谁                         |
|------------|-------------------|----------|--------------------------------|
| thunar     | GTK3 / Xfce       | 9.8 MiB  | 轻量 GUI，niri/Hyprland 都合适 |
| nautilus   | GTK4 / libadwaita | 13.8 MiB | GNOME 用户，原生 Wayland       |
| dolphin    | KDE / KIO / Qt6   | 16.3 MiB | KDE 用户，KIO 生态完整         |
| pcmanfm-qt | Qt6 / LXQt        | 3.1 MiB  | 只要一个极轻的 GUI             |
| yazi       | Rust / TUI        | 34.1 MiB | 终端里的预览、批量操作         |
| ranger     | Python / TUI      | 已安装   | 终端老用户，插件多             |

`nemo` 也能用，但它偏 Cinnamon 生态，和本机的 GTK 主题、依赖都不算最省。
如果没有 GNOME/KDE 的整套环境，不必为了一个文件管理器把它们的基础库拖进来。

## 2. Thunar 的安装与配置

### 2.1 为什么选 Thunar

- **依赖轻**：只拉 GTK3 和 Xfce 的几个基础库，比 Nautilus、Dolphin 小。
- **Wayland 可用**：GTK3 有 Wayland 后端；在 niri 和 Hyprland 下都能正常开窗。
- **桌面集成完整**：`gvfs` 负责回收站、网络位置和手机 MTP，`udisks2` 负责
  可移动磁盘挂载，`tumbler` 负责缩略图，`thunar-volman` 负责插入设备后的动作。
- **自定义动作简单**：右键菜单可以加“在这里打开终端”，配置文件是 XML，
  适合放进本仓库管理。
- **不绑定桌面**：不需要启动 Xfce 会话，也不依赖 Xfce 的面板或守护进程。

选 Nautilus 的情况：已经在用 GNOME，想要 GNOME 的文件选择器、缩略图和
在线账户完全一致。选 Dolphin 的情况：已经在用 KDE，需要 KIO、Baloo 和
KDE 的压缩包/网络集成。只想要最小 GUI 时，`pcmanfm-qt` 更轻，但功能也更少。

### 2.2 安装

```bash
sudo pacman -S --needed thunar thunar-volman gvfs gvfs-mtp \
  udisks2 tumbler ffmpegthumbnailer file-roller
```

各包的作用：

| 包                | 作用                               |
|-------------------|------------------------------------|
| thunar            | GUI 文件管理器本体                 |
| thunar-volman     | 插入 U 盘、光盘后的自动处理        |
| gvfs              | 回收站、网络位置、D-Bus 文件系统层 |
| gvfs-mtp          | 手机等 MTP 设备                    |
| udisks2           | 磁盘挂载与权限管理                 |
| tumbler           | 图片、文档缩略图                   |
| ffmpegthumbnailer | 视频缩略图                         |
| file-roller       | 压缩包查看与解压                   |

`udisks2` 通常已经随桌面环境装上；`--needed` 会跳过已安装的包。

### 2.3 配置自定义动作

Thunar 的自定义动作放在 `~/.config/Thunar/uca.xml`。本仓库用
`cfg_thunar/uca.xml` 管理，`init.sh` 会把整个目录链接过去：

```bash
./init.sh
```

`uca.xml` 里只放一个实用动作：在选中的目录上打开 `kitty`。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<actions>
<action>
	<icon>utilities-terminal</icon>
	<name>Open Terminal Here</name>
	<submenu></submenu>
	<unique-id>1730000000000000-1</unique-id>
	<command>kitty --working-directory %f</command>
	<description>Open a kitty terminal in the selected folder</description>
	<range></range>
	<patterns>*</patterns>
	<directories/>
</action>
</actions>
```

几个字段的含义：

- `%f` 是当前选中的路径；动作只对目录显示，所以它一定是文件夹。
- `<directories/>` 限定只对目录出现，不会在普通文件上误触。
- `unique-id` 只要在文件内唯一即可；改动作后换一个新值，Thunar 不会缓存旧项。
- `kitty` 必须在 `PATH` 里；如果平时用 `foot`，把命令换成
  `foot --working-directory=%f`。

改完后在 Thunar 里右键一个目录，应该能看到 **Open Terminal Here**。如果没
出现，先确认 `~/.config/Thunar/uca.xml` 是软链，再重启 Thunar。

Thunar 自己的视图选项（是否显示隐藏文件、列表还是图标、是否排序文件夹）
写在 `~/.config/Thunar/thunarrc`，由 GUI 设置页维护，不需要强行纳入仓库。

### 2.4 快捷键

Hyprland 的配置里已经是 `fileManager = "thunar"`；换文件管理器时只改这一处：

```lua
local fileManager = "thunar"
hl.bind(mainMod .. " + E", hl.dsp.exec_cmd(fileManager))
```

niri 的 `Mod+E` 还没有被占用，加一条：

```kdl
Mod+E hotkey-overlay-title="Open File Manager: thunar" { spawn "thunar"; }
```

如果也想从键盘直接开终端文件管理器，可以再加一条，但不要和现有的
`Mod+Shift+E`（退出 niri）冲突。例如用 `Mod+Shift+Y` 打开 `yazi`：

```kdl
Mod+Shift+Y hotkey-overlay-title="Open Yazi: kitty" { spawn "kitty" "-e" "yazi"; }
```

没有安装 `yazi` 时不要加这一条，否则按了没有反应。

## 3. Dolphin 的安装与配置

Dolphin 是 KDE 的文件管理器，不是 niri 的官方推荐项；它在 niri 和 Hyprland
下都能作为普通 Qt6 应用运行，不需要启动 Plasma 会话。它比 Thunar 功能多，
但依赖也重，会拉入 KIO、Baloo 等 KDE 组件。

### 3.1 安装

```bash
sudo pacman -S --needed dolphin
```

需要 Git/SVN 右键菜单时，再装可选的 `dolphin-plugins`。`kio-extras` 已经
作为 Dolphin 的依赖自动装好，不需要单独列。

### 3.2 首次启动

```bash
dolphin
dolphin ~/Downloads
```

Dolphin 不常驻；关掉窗口后进程就退出。它依赖的 `baloo_file` 索引服务可能
在后台运行，不需要索引时用 `balooctl6 disable` 关掉（旧版是 `balooctl`）。

### 3.3 常用配置

- **分栏/标签**：`F3` 开关分栏，`Ctrl+T` 新建标签，`F4` 开关内置终端。
- **网络与压缩包**：地址栏可直接输入 `smb://`、`sftp://`、`mtp:/` 或
  `archive:/path/to/file.zip`，由 KIO 处理，不需要先挂载。
- **文件操作**：复制/移动会进入队列，可以暂停、恢复，冲突时逐个选择；
  批量重命名在右键菜单里。
- **搜索**：默认走 Baloo 索引；不想建索引时关闭 Baloo，改用当前目录过滤。
- **右键菜单**：Dolphin 用 KDE Service Menu，不读 Thunar 的 `uca.xml`；
  自定义动作放到 `~/.local/share/kio/servicemenus/`。
- **外观**：在 `Configure Dolphin` 里调整视图、排序、预览和工具栏；这些
  设置写入 `~/.config/dolphinrc`，不需要跟 Thunar 共用配置。

### 3.4 与 Thunar 共存

两套文件管理器可以同时安装，不需要二选一。默认快捷键仍然给 Thunar，Dolphin
放在次级快捷键上：

- Hyprland：`SUPER+E` 打开 Thunar，`SUPER+Ctrl+E` 打开 Dolphin。
- niri：`Mod+E` 打开 Thunar，`Mod+Ctrl+E` 打开 Dolphin。

对应的配置项：

```lua
-- cfg_hyprland/hyprland.lua
local fileManager    = "thunar"
local fileManagerAlt = "dolphin"
hl.bind(mainMod .. " + E", hl.dsp.exec_cmd(fileManager))
hl.bind(mainMod .. " + CTRL + E", hl.dsp.exec_cmd(fileManagerAlt))
```

```kdl
// cfg_niri/config.kdl
Mod+E hotkey-overlay-title="Open a File Manager: thunar" { spawn "thunar"; }
Mod+Ctrl+E hotkey-overlay-title="Open a File Manager: dolphin" { spawn "dolphin"; }
```

Dolphin 的配置由本仓库的 `cfg_dolphin/dolphinrc` 管理，链接到
`~/.config/dolphinrc`；右键“Open Terminal Here”来自
`cfg_dolphin/open-terminal.desktop`，链接到
`~/.local/share/kio/servicemenus/open-terminal.desktop`。Thunar 仍然使用
`cfg_thunar/uca.xml`，两套自定义动作互不影响。

两个安装脚本都会同时安装 `dolphin` 和 `thunar`。如果只想留一个，删掉对应的
包即可；但不要把两个管理器绑定到同一个快捷键。

## 4. 终端文件管理器

`ranger` 已经安装，开箱就能用：

```bash
ranger
```

它的优点是 Python 生态、插件和文档多；缺点是启动和预览速度一般。`yazi` 是
Rust 写的，预览、异步加载和图片支持更好，但包更大，配置语法也不同。经常在
终端里翻目录、看图片和压缩包，可以换 `yazi`：

```bash
sudo pacman -S --needed yazi
yazi
```

两者都只是 TUI，不会接管桌面双击、回收站和 U 盘挂载；这些仍然由 Thunar +
`gvfs` + `udisks2` 负责。

## 5. 常见问题

| 现象                     | 原因                                | 处理                                           |
|--------------------------|-------------------------------------|------------------------------------------------|
| `SUPER+E` 没反应         | Thunar 未安装，或配置没 reload      | 先装 `thunar`，再执行 `hyprctl reload`         |
| 看不到手机或网络位置     | 缺 `gvfs` / `gvfs-mtp`              | 安装后重新登录，`gio mount -l` 检查            |
| U 盘插上不自动挂载       | `udisks2` 没运行                    | `systemctl status udisks2`，必要时 enable      |
| 没有图片/视频缩略图      | 缺 `tumbler` 或 `ffmpegthumbnailer` | 安装后清空 `~/.cache/thumbnails` 再打开        |
| 压缩包双击没反应         | 缺 `file-roller`                    | 安装 `file-roller`，或在 Thunar 里设置默认程序 |
| 右键没有自定义动作       | `uca.xml` 路径不对或 XML 写坏       | 检查软链，用 `xmllint` 验证 XML                |
| 以 root 打开文件管理器   | 不推荐，权限和主题都会出问题        | 用 `sudo -i` 做单次操作，不要长期开 GUI        |
| GTK 程序风格和终端不一致 | GTK 主题与终端配色是两套配置        | 先统一 GTK 主题，再谈文件管理器配色            |

## 6. 验收清单

- [ ] `thunar --version` 有输出。
- [ ] `gio mount -l` 能看到本地和已挂载位置。
- [ ] `udisksctl status` 能列出磁盘。
- [ ] Thunar 右键目录有 **Open Terminal Here**，点击后 kitty 落在该目录。
- [ ] Hyprland 的 `SUPER+E` 或 niri 的 `Mod+E` 能打开 Thunar。
- [ ] 插入 U 盘后能在 Thunar 侧栏看到并挂载。
- [ ] 图片和视频有缩略图；压缩包能双击打开。
- [ ] `ranger` 或 `yazi` 在终端里能正常预览文件。
- [ ] 若安装 Dolphin：`dolphin --version` 有输出。
- [ ] 若安装 Dolphin：`F3` 分栏、`F4` 终端、`Ctrl+T` 标签都正常。
- [ ] 若安装 Dolphin：`smb://`、`sftp://`、`mtp:/` 至少一种能打开。
